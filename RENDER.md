# Deploy SmartMetriQ on Render Free

1. Create a GitHub repository and upload this project, including `Dockerfile` and `render.yaml`.
2. In Render, select **New** > **Blueprint** and select the repository.
3. Render detects `render.yaml`. Confirm the **Free** plan and create the service.
4. Wait for the Docker build to complete, then open the generated `onrender.com` URL.

The Docker image installs Tesseract OCR and the English, Hindi, and Kannada language packs. It runs the app with Gunicorn, not Flask debug mode.

`SMARTMETRIQ_SECRET_KEY` is generated by Render from the Blueprint. If creating a Web Service manually instead, choose **Docker**, then add that environment variable yourself with a long random value. Also set `SMARTMETRIQ_SECURE_COOKIES=1`.

## Important free-plan behaviour

Render Free has an ephemeral filesystem. The SQLite file and uploaded images are erased whenever Render restarts or sleeps the service. SmartMetriQ automatically restores its three default demo complaints at startup, but it cannot restore real user complaints or uploaded evidence. Use this deployment for demonstrations only.
